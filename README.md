## Mise en ligne sur Vercel

1. Sur vercel.com : **Add New** › **Project**, puis importer ce dépôt GitHub.
2. Framework Preset : **Other**. Laisser vides Build Command et Output Directory.
3. **Deploy**.

Le fichier `vercel.json` sert le prototype à la racine du site. Les liens `/verifier/<numéro>`, `/suivi/<numéro>` et `/oeuvre/<numéro>` ouvrent directement la bonne page. Une fois en ligne, les QR codes pointent vers l'adresse du site déployé.
